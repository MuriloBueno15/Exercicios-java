# ☕ Exercícios de Programação em Java

Este repositório reúne exercícios e desafios práticos desenvolvidos durante meus estudos de Java e Engenharia da Computação.

O objetivo é aprimorar meus conhecimentos em lógica de programação, estruturas de controle, manipulação de dados e orientação a objetos.

## 🛠️ Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git e GitHub

## 📂 Organização dos exercícios

### 01 — Lógica de Programação

**CalculadoraSimples.java**

Programa que recebe dois números e realiza as quatro operações matemáticas básicas:

- Adição
- Subtração
- Multiplicação
- Divisão, com verificação de divisão por zero

**Conceitos aplicados:** variáveis, tipos de dados, entrada e saída, operadores aritméticos e estruturas condicionais.

## ▶️ Como executar

1. Instale o Java JDK.
2. Clone este repositório.
3. Abra a pasta do projeto no IntelliJ IDEA.
4. Localize o arquivo `CalculadoraSimples.java`.
5. Execute o método `main`.

## 🎯 Objetivos de aprendizado

- Desenvolver raciocínio lógico.
- Aprimorar a escrita de códigos Java.
- Praticar boas práticas de programação.
- Aprender versionamento de código com Git.
- Construir um portfólio de projetos.
